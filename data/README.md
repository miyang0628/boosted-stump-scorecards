# Data

This package **includes** the three public credit-scoring datasets used in the
experiments, so the notebooks run as-is. Each dataset belongs to its original
source (listed below); it is bundled here only for convenient replication.

| File | Dataset | Rows | Source |
| --- | --- | --- | --- |
| `cs-training.csv` | Give Me Some Credit (GMSC) | 150,000 | Kaggle: *Give Me Some Credit* competition |
| `german.data` | UCI Statlog German Credit | 1,000 | UCI Machine Learning Repository: *Statlog (German Credit Data)* |
| `heloc.csv` | FICO HELOC | 10,459 | FICO Explainable ML Challenge (`heloc_dataset_v1.csv`) |
| `polish_{1..5}year.arff` | Polish companies bankruptcy | 7,027–10,503 | UCI: *Polish companies bankruptcy data* (Zieba, Tomczak & Tomczak 2016) |

The Polish bankruptcy data are five cohorts (`1year`–`5year`) differing in
forecasting horizon and bankruptcy base rate (3.9%–6.9%), 64 financial-ratio
features (`Attr1`–`Attr64`) plus a binary `class`. They are used **only** by
`notebooks/R6_out_of_time.ipynb` for the out-of-time / temporal-robustness test,
not for the coefficient correspondence.

## Formats

- **`cs-training.csv`** — comma-separated, first (unnamed) column is a row index,
  target `SeriousDlqin2yrs` (1 = default).
- **`german.data`** — space-separated, no header, 20 attribute columns (coded
  `A11`, `A34`, …) plus a final target (1 = good, 2 = bad); notebook 05 recodes
  the target to 1 = bad.
- **`heloc.csv`** — comma-separated, header row, target `RiskPerformance`
  (`Good`/`Bad`). Codes `-7`, `-8`, `-9` are informative missing indicators,
  handled as their own WoE bins in notebook 06.

## Derived files (regenerated by notebook 01)

- `gmsc_clean.parquet`, `gmsc_woe.parquet`, `woe_maps.json` — shared WoE assets
  used by the downstream GMSC notebooks (02, 03, 04, 07).
- `german_named.parquet` — convenience copy of German with column names
  (notebook 05 reads `german.data` directly).
- `polish_{1..5}year.parquet` — the five Polish cohorts parsed from the `.arff`
  files (missing `?` → `NaN`, `class` cast to 0/1); read by `R6_out_of_time.ipynb`.

These derived files are included for convenience; running
`notebooks/01_eda_preprocess.ipynb` (GMSC) regenerates the GMSC assets exactly.
The Polish `.parquet` copies are produced from the raw `.arff` files by
`scipy.io.arff` (missing `?` → `NaN`, `class` → 0/1) and are read directly by
`R6_out_of_time.ipynb`.
